# Galaxy Catcher

Game web sederhana bertema luar angkasa. Pemain menangkap bintang dan menghindari meteor.

## Teknologi
- HTML
- CSS
- JavaScript

## Cara Bermain
Gunakan tombol panah kiri/kanan atau A dan D untuk menggerakkan pemain.
